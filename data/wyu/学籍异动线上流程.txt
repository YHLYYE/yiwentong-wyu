学籍异动线上申请与审批流程（2026-04-15）

 依据：《关于启用学籍异动线上申请与审批流程的通知》，教务处，2026-04-15。
 来源：https://www.wyu.edu.cn/jwc/info/1098/13881.htm
 适用范围：休学、复学、保留学籍、留级、退学等学籍异动。

一句话答案

先在教学管理系统或企业微信提交线上申请、上传材料；线上审批通过后，仍须把纸质申请表和材料原件交到教务处学籍与考务科，领取异动证明，流程才算结束。

办理前
先联系所在学院辅导员（班主任）或学院学工办，确认本人符合申请条件；
再登录系统提交；材料不全、不符合规范、未按要求签署承诺的，会被驳回。

线上入口

电脑端

五邑大学教学管理系统 → 业务办理 → 学籍变动 → 学籍变动申请 → 点击左上角 “+增加” → 选择异动类别。

移动端

五邑大学企业微信 → 工作台 → 教务系统 → 学籍变动 → 右下角“我的异动申请” → 点击“增加” → 选择异动类别。

线上流程

1. 填写相关信息；
2. 上传支撑材料；
3. 提交审核；
4. 相关部门/负责人审批：
审核无误：选择“通过”并保存；
需要修改：选择“退回”，指定退回节点为“申请人”；
不允许申请：选择“不通过”；
5. 线上审批完成后，学生把纸质申请表 + 支撑材料原件交教务处学籍与考务科；
6. 领取相关异动证明，异动结果分发各有关部门。

 通知要求：原则上异动申请当天办理完成，最多不超过 3 天；特殊情况学院应及时告知教务处学籍与考务科。

材料清单

复学

1. 学籍异动申请表（附件 1）；
2. 身份证正反面；
3. 家长知情同意书（附件 2）；
4. 家长身份证正反面或户口本（首页、家长页、学生页）；
5. 情况证明：
因病休学期满复学：二级甲等以上医院康复证明 + 学校医务室意见；
退役复学：退役证书。

休学

1. 学籍异动申请表（附件 1）；
2. 身份证正反面；
3. 家长知情同意书（附件 2）；
4. 家长身份证正反面或户口本（首页、家长页、学生页）；
5. 情况证明：
因病休学：二级甲等以上医院诊断证明 + 学校医务室意见；
其他原因：相应证明材料或情况说明。

保留学籍（征兵入伍）

1. 学籍异动申请表（附件 1）；
2. 身份证正反面；
3. 家长知情同意书（附件 2）；
4. 家长身份证正反面或户口本（首页、家长页、学生页）；
5. 入伍通知书。

留级

1. 学籍异动申请表（附件 1）；
2. 身份证正反面；
3. 家长知情同意书（附件 2）；
4. 最新打印的成绩单（成绩原因者）。

退学

1. 学籍异动申请表（附件 1）；
2. 身份证正反面；
3. 家长知情同意书（附件 2）；
4. 家长身份证正反面或户口本（首页、家长页、学生页）。

格式要求

1. 附件 1、附件 2 必须打印后手写签字，不可电子签名；
2. 上传材料必须完整、内容清晰可辨；
3. 因病休学/复学的诊断证明必须有医院公章，未盖章无效；
4. 委托办理：除上述材料外，还需《学籍异动委托办理授权委托书》（附件 3）+ 双方身份证复印件；
5. 最终归档：线上审批结束后，申请人须把线上上传的全部材料纸质版交教务处学籍与考务科，才能领取异动证明。

常见误区

| 误区 | 正确做法 |
 
| “线上点完就结束了” | 线上审批后还要交纸质原件、领异动证明 |
| “电子签名就行” | 申请表/知情同意书必须打印后手写签字 |
| “医院证明拍照就行” | 必须有医院公章；材料要清晰完整 |
| “先提交再问辅导员” | 先联系辅导员/学院学工办确认符合条件，再线上申请 |
